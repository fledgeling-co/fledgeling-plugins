# Changelog

## 0.5.0 - 2026-09-01

A second mode, from a measured gap in how the skill was already being used. Between 18 August and 1 September 2026 six sessions invoked `geminify:geminify`; three of them were runners calibrating themselves rather than authoring anything, and the skill had no procedure for that case. One of the three (`graft/aa239a23`) loaded five skills and read zero `gemini.md` files while running on Gemini, and nothing detected it because nothing counted. A fourth (`Dev/de51503f`) asked for a real `gemini.md`, ran `scan_skill.py`, then wrote nothing, gated nothing and installed nothing.

- **Mode B — calibrate the session you are running in.** Four steps: build the ledger, read every `gemini.md` it lists and report the count, post a receipt table where a Skill tool call discharges a row, then hold four overrides for the rest of the session. Mode A is the existing six-step authoring procedure, unchanged. A target named in the invocation selects A; no target selects B.
- **`scripts/session_calibrate.py`.** Reports `gemini.md` coverage per loaded skill with a read-count denominator, the referral lanes that are out-of-family for the serving model, and an unticked receipt ledger. It also separates two facts a runner cannot otherwise tell apart: a skill that is on disk, and a skill the Skill tool can resolve. `create-test-suite` sits in the plugin cache at 0.3.0 and is absent from its marketplace's 53 published entries; ten Skill calls naming it returned `Unknown skill` while the directory existed the whole time.
- **The receipt distinction is the mode's centre.** One recorded session defended a skipped step with *"I executed their underlying scripts directly rather than re-issuing duplicate Skill tool calls for skills already loaded"*, and the skills it named had never been invoked in that session. Conforming output is not a receipt; the tool call is.
- **Detection moved out of prose and into a hook.** `~/.claude/hooks/geminify-on-gemini.py` fires on `SessionStart` (declared model), `PostModelSwitch` (a `/model` switch), and `UserPromptSubmit`, which reads the last assistant turn's `message.model` from the transcript. The third event exists because Relay re-routes at the proxy layer without changing Claude Code's model setting, so a session can be served by `anthropic/relay/agy:default` while both other signals still say Claude. Measured on a 28 MB transcript at 0.07s, inside `UserPromptSubmit`'s 30-second budget.
- **What the window does not establish.** No Gemini run of Mode B has been observed — it is new in this release, so every claim about its effect is `[derived]`. The corpus behind it is flash-tier only (473 of 499 Antigravity sessions on Gemini 3.7 Flash High), and the in-family referral count (225 of 2,062 `agy` dispatches) counts dispatches rather than verdicts a caller acted on.

## 0.3.0 - 2026-08-23

A third measured source: `COD Dossier`, 23 August 2026 — a full deep-research-and-page-synthesis run of `dossier-report` under `gemini-3.7-flash-high` inside Claude Code, recorded in `references/evidence.md` §1.2. Where §1.1 watched a build brief and §2 is a bench rate, this session watched a skill *composing other skills*, and the failures land there. It stays n=1 and the file says so.

- **Sequential artifact dependencies join C4.** The run's skill said *"Every design decision goes through `design-craft` with `ux-craft`'s lens"*; neither skill was invoked, and the model's own diagnosis named the mechanism — the rules were already in context and nothing downstream required a file only those skills produce. C4 now says multi-skill composition is phrased as an executable chain (Phase N emits `DESIGN.md`/`UX.md`, Phase N+1 reads it), never as a lens or standard, with a filled tool-sequence example.
- **`scan_skill.py` lists qualitative skill references.** A new high-precision scan surfaces "goes through X", "routes through X" and "with X's lens" phrasing so each can be converted to an artifact-gated phase. A first draft matched 16 plugins on bare `via` and `follows`, burying the real rows; tightened to routing verbs plus a bounded gap plus a skill-shaped name, it fires on 5 files and every hit is real — including two siblings (`report`, `email-digest`) carrying the exact phrasing that failed.
- **The `gate` module requires prerequisite receipts.** The run's auditor validated tags, citations and contrast, and passed cleanly with the upstream skill passes skipped — exit 0 with no check that `DESIGN.md`/`UX.md` existed. Audit scripts now must check prerequisite artifacts exist before checking final properties, and fail when an upstream pass was skipped.
- **C3 covers hard capacity limits.** The run retried a 25k-token-capped `Read` four times with offset tweaks before pivoting to a Python split. A capacity error now pivots on attempt 1 — chunking, streaming, or a helper script — rather than consuming the two-attempt ceiling on an unwinnable call.
- **C7 extends to files named in the prompt.** Asked a question naming three skills, the run answered from memory without loading any; asked to fix it, it launched a skill instead of answering. Read-then-answer, as two ordered steps, neither substituting for the other.
- **C6 gains a tier line, backed by a new corpus section.** Every measured rate in this skill is flash-tier, and the family's `thinking_level` defaults have drifted — the corpus now carries Google's own sentences: the family defaults to `high`, 3.5 Flash moved the default to `medium`, 3.7 Flash lists only low/medium/high, and higher levels drive more tool calls. A `gemini.md` names the model its measured claims were observed on and does not project flash rates onto Pro, where the overrides hold as `[docs]` discipline and the numbers are open questions.
- **A targeted research sweep corroborates the session findings and is filed as such.** Two workers read primary Google docs and first-hand community reports (Dossier run `dr_e9cd821d304bcdba`, exported to `docs/deep-research/gemini-3x-instruction-following.md`): an Antigravity user's subagents ignoring instructed skills on 3.5 Flash, a Gemini 3 **Pro** transcript downgrading a GEMINI.md rule to "a general guideline", fabricated tool success closed as a duplicate class, and gemini-cli's own loop detector. Recorded in `references/evidence.md` §7.2 as corroboration of §1.2's mechanisms — citable as `[derived]` with provenance, never as a measured tier. The sweep's sharpest negative is also recorded: nobody anywhere has A/B'd the exact phrasing distinction C4 turns on.
- **Third-party panel claims got their own section instead of a measured tag.** Three claims relayed by Dossier research reports (same-family grading inflation, file-artifact coordination, brevity's accuracy cost) are recorded in `references/evidence.md` §7.1 as unverified third-party material — citable from a `gemini.md` only as `[derived]` with that provenance named, never as `[docs]` or `[measured-family]`. A first draft had filed them inside the benchmark section; that is the tier-blurring this skill exists to prevent, caught on re-review.

## 0.2.0 - 2026-08-22

A second measured source, and the failure it exposes points the opposite way to the first one. Until now every claim in this skill traced to one session on one brief: `n=1`, honest about it, and silent on non-visual work. It now also rests on 106 benchmark tasks scoring `gemini-3.7-flash` at both effort levels against `claude-opus-5` — which is a rate, on the exact model the skill is written for, with cross-model and same-scaffold controls.

- **A new module, `bounded-constraint`, for the failure direction C1 does not cover.** The quota ledger catches a categorical scope collapsing to one instance: under-delivery. This catches a stated maximum exceeded on every instance: over-delivery. Measured, 58% of failing UI assertions at `medium` and 86% at `high` were bound-shaped (`exactly N`, `no`, `not`, `only`) against 8% for opus and 6% for the OpenAI lane, and the most-repeated one — `has exactly one soft elevation shadow` — failed on every card and every toast in its set on a run that passed 37 of its 39 other assertions. The brief stated it numerically. Restating it more firmly is not the fix; a bound ledger filled by reading the produced value off each instance is.
- **`scan_skill.py` emits that ledger.** A second high-precision regex lists numeric and singular limits with their line numbers, and counts prohibitions in prose without listing them — the same trade the quota regex already makes, for the same reason. Verified on three targets: `design-craft` 8 bound rows and the module fires, `clarify` 2 rows and it does not.
- **A new core section, C9, the route-out block.** Some gaps are not prompt-fixable. Two of eight measured work buckets produce a hard zero on the majority of decided rows — self-contained pages authored from prose (22 against opus's 67) and brownfield edits to an existing repo (16 against 46) — so a `gemini.md` for a skill that does that work names the shape and hands over `lane_pick.py` rather than trying harder. It carries the checklist's own sentence about a task outside the model's capabilities, and two conditions that keep it from becoming a general nag: no block for a skill that judges rather than builds, and no row for a shape the target never produces.
- **C6 gains the caveat that stops `thinking_level` being sold as a remedy.** Paired across all 106 tasks, `high` beat `medium` on 24, lost on 24 and tied on 58 — mean −1.7 points. The bench's own sanity checker flags an effort inversion; the paired count says it is a coin flip.
- **The `visual` module gains a second lever.** Google's launch material claims high design adherence *from a reference input*. Every collapsed static-page task was a prose brief with no reference, so the corpus measured the mode the vendor does not claim. Written as the documented strong path, marked unmeasured.
- **Three findings were investigated and thrown out, and the file says so.** Environment damage (51 of 140 decided container rows against 2 of 235 on the host) is a harness artifact, not the model. Output instability is ordinary — 8% and 13% cell disagreement against opus's 12%. And every benchmark row ran at `temperature: 0` against Google's explicit advice for the 3.x family, which is why the same-scaffold control is load-bearing and the raw gap is an upper bound.
- **The corpus gained the five vendor passages the new sections quote**, and the evidence tier for `[measured-family]` widened from "a Gemini run of another skill" to "a Gemini run that is not this skill". `verify_quotes.py` caught one violation while this was being written — a phrase of the author's own in double quotes inside a `[docs]` paragraph — which is the second time that gate has earned its place.
