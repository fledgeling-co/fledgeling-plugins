Which model does this work go to?

One routing policy for every skill that hands work outside the session. The task class picks the family; measured plan headroom picks the lane inside it.

lane_pick.py --task completeness  →  lane, effort, argv, and the check that proves it ran

Six task classes, seven lanes, five model families. A cell holds the effort that lane runs at for that class — pinned, because a lane that inherits its config default is not the lane anyone chose.

Where a class names several lanes, order does not choose between them — measured headroom does. Where it names one, that is policy, though a spent lane is still skipped for the next one the class allows.

Three rules above the table

These are the ones habit gets wrong, so they are stated rather than left to be read off the grid.

01

Sol never runs at max

gpt-5.6-sol is the referral lane at medium. Work that is not a referred decision goes to gpt-5.6-terra at high — the same context window at a fraction of the price.

02

Fable judges; it does not verify

Forks, design calls and referred decisions, yes. Grading code or a ticket against its acceptance criteria, no — that is claude-opus-5 at xhigh.

03

Design review stays on Claude

Opus and Fable only. No other family reviews rendered UI here, so the design-review row is the one place the out-of-family default is deliberately not applied.

Tier 1 is a utilization percentage the vendor computed, already sitting on disk — Relay's usage.json for Claude, and codex's own rate_limits payload. Tier 2 is counted locally and divided by a budget you set, which makes it an estimate wearing a number. Grok, GLM and Gemini expose no quota to any CLI, so they cannot be anything else; calibrate their budgets from a percentage you can read yourself with lane_pick.py --calibrate gemini=62.

Invocation, per lane

What lane_pick.py prints, and what lane_run.sh runs. Each lane carries the check that proves it ran as routed, because the expensive failure in a multi-model system is a plausible answer from the wrong model.

gemini gemini-3.7-flash-high · google $4.50 / Mtok blended
agy --model gemini-3.7-flash-high --output-format json -p "<prompt>"

Verify: non-empty output. There is nothing else — agy records no model id, no tokens and no cost. --output-format json is the only place a token count for this lane exists anywhere.

grok grok-4.6 · xai $8.00 / Mtok blended
grok -m grok-4.6 --effort xhigh -p "<prompt>"
# harness fallback
cursor-agent -p --force --model grok-4.6 "<prompt>"

Verify: a turn_completed record under ~/.grok/sessions/. Exhaustion arrives as a 402 in the transport, not on stdout.
