# Changelog

## 1.2.0 - 2026-08-22

The Gemini evidence clamp keeps its behaviour and loses its justification. Until now, the reason a proxy row could never hard-block a lane was that Gemini's worst shapes had been measured through a bash-only container scaffold, and reading that as a verdict on the `agy` lane would retire a lane on a confound. That was reasoning, not evidence. It has now been tested, and for the shape it was doing the most work on it is wrong.

- **A same-scaffold control, and it kills the scaffold explanation for `static-page`.** Hold the harness constant — same seven tasks, same current contract, same mini-in-a-container loop — and seven other models clear 62–83%: `qwen3.8-max` 82.9%, `grok-4.5` / `muse-spark` / `glm-5.2-fast` / `deepseek-v4-flash` 80%, `kimi-k3` 77.8%, `deepseek-0731` 61.8%. Gemini scores 42.9% at `high` and 35.3% at `medium`. The bash-only loop is not what makes this shape hard, and the argument that it was should not be reinstated.
- **On `brownfield-integration` the same control says the opposite, partly.** That cohort spans 20 to 65 with Gemini at the bottom, so the scaffold is doing real work *and* the model is behind. The 30-point gap to opus is part harness, part model, and this control cannot say in what proportion. The file now says that instead of implying the scaffold covers it.
- **The clamp survives on a different, stated reason.** Mini pins `temperature: 0` for every route it drives, and Google flags sub-1.0 temperature as degrading for the Gemini 3.x family specifically — a warning the control models do not inherit, so the within-scaffold comparison stays fair while the lane comparison does not. The `agy` lane and the opus reference both set no temperature at all. A vendor-flagged degradation setting on one side is not a basis for retiring a lane. `shape_grade`'s docstring and the `gemini` lane's registry comment now carry that reason rather than the disproven one.
- **`static-page` is the one shape whose failure mode is known, so its guard names it.** On those tasks 58% of Gemini's failing assertions at `medium` and 86% at `high` state a bound (`exactly N`, `no`, `not`, `only`), against 8% for opus and 6% for `sol@max`. It delivers what the brief asks for and exceeds what the brief caps — `exactly one soft elevation shadow` failed on every card and every toast in its set on a run that passed 37 of its 39 other assertions. The guard now asks for a reference input and for each produced value to be read back against every stated bound, rather than for more care. `visual-design` picks up the same clause.
- **What would actually lift the clamp is named, and it is cheap.** The seven `static-page` tasks re-run through `agy` at default sampling. Nobody has run it. Until someone does, the grade stays AMBER over a raw RED and `--matrix` keeps marking the cell.

No scores, gates, thresholds or routing decisions changed. `capability_matrix.json` is untouched; this release changes what the numbers are taken to mean.
