**A test needs its threshold written before it runs.** "Run a landing-page test"
without a stated pass line is a test that returns whatever the reader wants,
because every result is interpretable after the fact. Write the number first.

## Standing caveats on the instruments

{{INSTRUMENT_CAVEATS}}

Stated-preference methods measure what people say, which is not what they do.
Any test in the table that elicits an opinion rather than an action is marked as
such, and its result is weaker evidence than its precision suggests.
