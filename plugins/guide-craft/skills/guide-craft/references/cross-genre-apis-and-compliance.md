# Cross-Genre Data Planes, Statistical Provenance and Compliance

Load this file during Stages 2, 3, and 8 whenever building a season guide outside closed-API shooters, integrating official game APIs, ranking telemetry win rates, or preparing an iOS companion app for App Store Review. Every rule below traces to the 3-family Phase 1 research corpus in `docs/deep-research/` (Gemini Deep Research, xAI Grok 4.7, and Perplexity Sonar Deep Research, verified November 2026).

## 1. Four-tier data-plane architecture by genre

Do not build a universal scraper. Pick the ingestion tier the game's publisher actually permits, and never embed publisher API keys or OAuth client secrets inside a shipped iOS binary (explicitly forbidden by Riot, Grinding Gear Games, and Wargaming). Route all authenticated API calls through a backend cache/CDN proxy.

| Tier | Ingestion mechanism | Genres and documented sources (2024–2026) | Hard operational and legal constraints |
|---|---|---|---|
| **Tier 1: Official OAuth / keyed REST APIs** | Backend caching proxy + scheduled manifest sync + dynamic rate-limit header tracking | **MOBAs / Hero Shooters / TFT:** Riot Developer Portal (Personal `20 req/1s`, `100 req/2m` strictly private; Production starts `500 req/10s`, `30,000 req/10m` per region; dev keys expire every 24 h; RSO OAuth for VALORANT/private matches; Data Dragon static catalog). **MMOs / Card / Shooters:** Battle.net (`100 req/s`, `36,000 req/hr`, **30-day max data TTL**); Bungie.net Destiny 2 (`<=25 req/s`, cache `/Manifest/` locally rather than chatty per-entity calls); Steam Web API (`100,000 calls/day`, batch up to 100 SteamIDs, ~200/5 m per endpoint); Path of Exile OAuth 2.1 (mandatory `User-Agent`, dynamic `X-Rate-Limit-*`, **5-min Public Stash delay**, ladder capped at **15,000 PoE1 / 1,000 PoE2**); Wargaming (`20 req/s` server / `10 req/s` IP); PUBG (`10 req/min` free); iRacing `/data` OAuth2 (`RateLimit-*` headers, **affirmative revocable member consent** before publishing display names/`custid`). | Never run a public product or beta on a Riot Personal/Dev key; register one Riot app per game. Obey TTL deletion windows (Blizzard 30 d, EA FC 28 d). An API key is a technical grant, not automatic commercial permission (iRacing, Bungie). |
| **Tier 2: Client codecs & local UDP telemetry** | 100% client-side clipboard string encoders/decoders + local Wi-Fi UDP listener | **Card / ARPG / MMO / Shooters:** Hearthstone Deckstring (Base64 varint DBF IDs: `0x00`, Ver 1, FormatType, sorted heroes/1-of/2-of/n-of; `### <Name>` title line); Path of Building (URL-safe Base64 + zlib XML + PoE2 `.build` JSON + browser-side AI JSON prompt export); WoW Base64 talent strings (verify after pre-patches; stale strings hang clients); CoD 14-char Gunsmith build codes (`A01-5XGZH-JSLZ5-1`, unlocked Level 4). **Sim Racing:** EA Sports F1 25 local **60 Hz UDP** (Format 2025, Port 20777). | Console players type 14-char codes slower than manual picks: always show a high-contrast visual slot-by-slot card above every copy button on mobile. Validate export strings on every patch day. |
| **Tier 3: Structured community wikis** | MediaWiki `Extension:Cargo` (`action=cargoquery` JSON/XML or `Special:CargoExport`) | **Fighting Games:** SuperCombo, Dustloop (`{{MoveData}}` frame tables, combo routes, matchup notes). **Community aggregators:** OpenDota (`60 req/min`, `50k/mo` free; read `per_min`/`per_month` headers), Raider.IO (OpenAPI, `200 req/min` unauth, mandatory link-back). | Respect wiki scrape etiquette (SF6Frames.com shut down from bot abuse). Never ship hitboxes extracted via modified clients: Capcom issued a **23 Oct 2026 takedown** against Ultimate Frame Data over SF6 hitboxes. |
| **Tier 4: Closed-API clean-room editorial + empirical tests** | Official patch notes, firing-range/lab measurements, calculators, and codecs | **Closed Shooters / BR / Sports:** Call of Duty, Apex Legends, Fortnite live matches, non-whitelisted EA Sports FC (EA's **27 Jul 2026 FC Community API** is closed exclusively to FUT.GG, FUTBIN, and FUTWIZ), Capcom fighters. | Do not invent fake win rates or scrape closed web apps (EA ToS Sec. 6 bans accounts; scraping fails Apple Guideline 5.2.2). Label every stat `Lab` or `Editorial`. |

## 2. Five provenance badges and seven statistical validity rules

Never blend telemetry win rates, ladder survivors, opt-in PC trackers, lab measurements, and creator opinions into one unlabelled tier list. Attach one of five provenance badges (`official_telemetry`, `ladder_snapshot`, `pc_opt_in_tracker`, `lab_measurement`, `editorial`) plus sample count `n` to every ranked row, and run `scripts/audit_sources.py` on every build.

1. **Rank-bracket skew & 72-hour promotion lookahead bias:** Filtering matches by a player's current rank rather than pre-match lobby rank inflates Grandmaster+ average win rates to 54.14%, depresses Iron to 42.54%, and produces 69.71% win rates in cross-tier promoted matches (Lolalytics vs u.gg audit, Patch 16.17). Either bucket by pre-match lobby rank or subtract the tier baseline (`WR - Tier Mean`, normalized matchup `Δ2`) prominently beside every percentage, and never render a build recommendation without a visible rank bracket and sample count.
2. **Win-rate vs pick-rate / ban-rate & Simpson's paradox:** A high win rate at tiny pick rate reflects dedicated one-tricks or counter-picks, not universal strength. Stratify by control scheme (Classic vs Modern in SF6), mode (MP vs Warzone), and mastery depth (`50+` games), and display win rate alongside pick rate and ban rate (or card `IWD = GIH WR - GND WR` so weak filler cards carried by dominant decks are not ranked S-tier). For TFT, obey Riot's explicit ban on displaying win rates for Legends or Legend-based Augments (and all Riftbound win/play rates).
3. **Patch-boundary & unversioned server-hotfix poisoning:** Server-side balance updates (such as Hearthstone 37.0.3 on 17 Nov 2026) alter gameplay without incrementing the client version string. Partition telemetry by a composite `(client_version, balance_hotfix_timestamp)` key derived from match payloads (never rolling clock windows like `"last 7 days"`), flush caches on patched items, display both client version and hotfix date in the mobile header, and hold public patch cutovers until a declared sample floor is met.
4. **Low-sample smoothing:** Wald confidence intervals fail on small `n`. Sort telemetry builds by the **95% Wilson score lower confidence bound** or **Empirical Bayes shrinkage** toward the bracket baseline, and enforce a hard display floor (`n >= 50` minimum per build/specialist, higher for full tier placement).
5. **Opt-in tracker selection bias & ladder survivor bias:** PC-only trackers (17Lands ~55%–55.4% WR) exclude mobile/casual players (+5 pp skew); ladder APIs (poe.ninja top 15k PoE1 / 1k PoE2) measure high-XP survivors, not league averages. Center win-rate colour scales on the cohort mean and display `PC Opt-In Tracker` or `Top 1,000 XP Ladder` badges.
6. **Datamine vs empirical testing conflicts:** In closed-API shooters, raw datamined weapon scripts diverge from live gameplay when secondary engine caps override tables (Warzone TAQ-V: Sym.gg 513 RPM datamined vs TrueGameData 361 RPM frame-tested). Badge `Datamined` vs `Frame-Tested` explicitly and flag active discrepancies.
7. **Economy ask-price bias & creator divergence:** Public stash feeds list asking prices, not cleared trades; filter price-fixed outliers rather than reporting minimum ask. Keep creator/editorial tier explanations beside live telemetry rather than hiding disagreement (champions get nerfed for ban frustration and pro presence even outside top-20 solo-queue win rate).

## 3. App Store IP, naming and publisher monetization compliance

Shipping an unofficial iOS companion clears two independent gates: Apple App Review and publisher IP enforcement. Run `scripts/check_compliance.py` on the app release manifest before creating an App Store Connect record or uploading a release candidate.

- **Apple Guideline 4.1(c) (added 13 Nov 2025) and 5.2.1:** Guideline 4.1(c) explicitly bars using another developer's icon, brand, or product name inside your app's icon or name without developer approval. Guideline 5.2.1 bars unlicensed trademarks, game screenshots, and **AI-generated icons that mimic recognizable characters, emblems, or studio aesthetics**. Writing `"Unofficial"` in the subtitle is not a license. Default to an original ownable app name and original icon, express compatibility clearly in the description, and avoid official game art in App Store screenshots unless licensed.
- **Apple Guideline 4.2 (Minimum Functionality) and 5.2.2 (Third-Party Authorization):** Never ship a WKWebView wrapper around the static web guide (fails 4.2); justify the native binary with bundled offline data, native codecs/calculators, shaders/3D inspect, narration, and voice. Under 5.2.2, Apple can demand proof that the publisher's ToS allows your data ingestion and monetization.
- **Live voice & overlay legal boundaries:** Apple bans ads inside Siri/Shortcut responses and App Clips. Riot banned Enemy Ultimate Timers (13 Mar 2025), in-game/loading-screen overlay ads (29 May 2025), and unknown third-party game-memory access (6 Oct 2026, Apr 2027 grace for approved tools) while forbidding real-time decision-dictating overlays; Overwolf rejects persistent gameplay overlays; GGG caps clipboard/screen reads at 1 manual keypress per action. Keep live voice assistants strictly **out-of-match / pre-match / post-match** (or 60 Hz local UDP sim-racing telemetry), and never clone publisher character or actor voices.
