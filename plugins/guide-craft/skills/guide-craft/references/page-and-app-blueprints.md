# Page, App and Interactive Tool Blueprints

Load this file during Stages 3 and 4 to reproduce MW4's full 16-page web architecture, 5-tab iOS shell, 7 interactive calculators/simulators, single-source dataset, and Duo layout on any live-service game.

Group pages into 5 JS-free `<details>` menus on desktop (`.ngrp`/`.navmenu`) and a plain-list `<details class="mnav">` sheet on phones. Drop PC-only pages for console/mobile games and swap nouns for the target genre.

## 2. Complete 5-tab iOS app + full-screen Voice blueprint

Put `.searchable(text:placement: .navigationBarDrawer(displayMode: .always))` on every non-voice screen (disabled on split detail panes) with destination-based links. ## 3. Seven interactive tools and models

1. **6-area Settings Workbench (`site.js`):** independent sliders per graphics area, 5 presets, GPU + resolution picker, vendor-aware upscaler labels, 1440p-and-below Quality floor, `localStorage` persistence, clipboard export with manual fallback, and zero-JS static table fallback.
2. **Calibrated Damped FPS Estimator:** linear percentage sums double-count GPU work; use damped area scaling `base * (up / BASE_UP) * (S(lv) / S_EXT) ** DAMP` where `DAMP = ln(PRESET_SPAN) / ln(1 / S_EXT)` (`~0.55–0.575`), per-resolution upscaler gains (`QGAIN`), cross-card resolution ratios (`R_1080`, `R_UW`, `R_4K`, `R_5K=0.82`), multiplayer uplift (`+7%`), 8 GB vs 16 GB penalty (`-2%` + stutter warning), and CPU ceiling (`240+` / `>=170` flag). Tag every value `Lab`, `Scaled`, or `Placed`; disable unmeasured resolutions; separate interpolated cards in `<optgroup>`.
3. **Best-Settings-For-Your-Card Advisor:** single deterministic function in the generator computing best-looking preset reaching target fps (`144`/`100`/`60`, or `"not reachable"` with fastest preset figure), upscaler by GPU architecture (splitting hardware FP8 vs software INT8 and older CNN vs Transformer), and textures by VRAM (`>=16` High, `12` Normal, `<=8` Low), exported identically to HTML, `guide.json`, and voice.
4. **Play-Style Switcher + TTK-by-Range Chart + Agreement Matrix:** per-class tabs switching builds/unlocks/icons, scrubbable Swift Charts (selection haptic per step) and inline dark SVG polylines (`<=5` series, captioned `"Time to kill, lower is faster"`), plus visible cross-source agreement matrices.
5. **Three-Clock Mechanics Simulator & Fight-Length Calculator (`sponge.js`):** 3 horizontal time lanes (`Their screen`, `Server`, `Your screen`), ping sliders (`pa`, `pb`), packet-burst toggle (`#sp-burst`), scrubbable playhead with live dynamic summary sentence, plus calculator comparing paper TTK vs your kill vs perceived death speed (hidden play button under reduced motion).
6. **3D Tactile Inspect Plate & 3D Map Table (`Effects.swift`, `FieldExtras.swift`):** see `references/polish-and-ship-playbook.md` Section 2.
7. **Integrity / Lobby-Odds Calculator:** interactive slider for per-player cheater rate and lobby size computing `1 - (1 - p)^N` with rolling numbers and curve, keeping per-match and per-player disclosures strictly separate.

## 4. Data schema, exporter hygiene and copy rules

- **Single-source loading:** `build/site.py` shadows Python stdlib `site`; import via `importlib.util.spec_from_file_location('gsite', ...)`.
- **Row shapes:** Sources `(id, title, url, note)`; Picks `(role, name, build, why [[r..]], is_pick)` + separate 1–2 sentence `APP_WHY` -> optional `Role.brief`; Current Meta `(update date, 1-sentence lead, 6 picks, rising, next)`; Season `(start/end/ISO/endConfirmed/sources, 1-sentence playing, 4 points, 4 favourite maps, split maps, league note, news rows)`; Settings `(menu section, in-game label, area, preset values, cost spread, agreement, flag, why, sources)`.
- **Schema & exporter gates:** additive-only `guide.json` (`Optional` in Swift); untested numbers exported as `null` (never `""`); strip `<sup ...>...</sup>` before generic HTML tag removal; clean scraped residue (`apex_name()`) and guard bare strings against `" ".join()` letter-splitting; type-guard recursive `"sources"` walks against dict lists (`all(isinstance(x, str) for x in v)`); assert `unresolved source ids: none` and page existence for every meta pick and favourite map; run `scripts/check-html.py` (zero nested `<a>` links) and the 2–4 s standalone macOS `swiftc` decode harness (stripping `\bstatic\b.*\bshared\b` lines from `Model.swift`).
- **Copy & chip rules:** app states what an item does in 1–2 sentences (evidence stays on web); one deduplicated `PageSources` per section/page (per-item sources only on actionable estimates/contested picks); one unified `AgreementChip` (`N of N` never also marked split; `"Guides split · 5 of 9"`; `"7 of 9 guides: between 50 and 75"`); hide empty `flagLabel` chips; label positive `+` big settings `"Big gain"` (never `"Big cost"`) on both web and app; use `\u{00A0}` non-breaking spaces in inline metric pills (`"65\u{00A0}at\u{00A0}4K"`) and non-breaking hyphens in narrow titles (`"12‑player"`).

## 5. iPhone Duo layout and 6-surface state matrix

- **Duo posture rules (`duo-craft:duo-craft`):** branch on measured window width plus `UIView.reservedRegions(kind: .division, options: .includeInactive)` and `UIHingeInteraction`, never device model. Closed (`466x678`): single column pushes. Open flat (`951x669`): 320 pt fixed list + detail (fold inside detail). Book: divider moves to fold. Open portrait: regular single column. Tabletop: detail on raised top half, list on flat bottom half. Split View: per-pane safe-area insets. Always populate default detail selection and keep chosen item pushed when closing.
- **Open-flat `TabView` trailing-inset fix:** `.ignoresSafeArea(.container, edges: .trailing)` does not strip `TabView`'s trailing sidebar inset from the left list pane; widen the left list by `+ geo.safeAreaInsets.trailing`, apply `-geo.safeAreaInsets.trailing` trailing padding, and place at `zIndex(0)` under detail (`zIndex(1)`).
- **Explicit state matrix (zero loading spinners because data ships bundled):**

| Any list + detail | n/a (bundled; defaults to first row) | populated readout | Long setting names wrap, never truncate | n/a |
