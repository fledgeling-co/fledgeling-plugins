# Visual, Shader, Voice, Audio and Shipping Playbook

Load this file during Stages 5 through 9 to reproduce MW4's visual craft, tactile motion, Metal/WebGL shaders, voice guide, narrated radio audio, app icon, shipping workflow, and visual critique loop.

## 1. Visual direction, Mobbin trawl and anti-slop rules

- **Visitor mode:** **Read, with Operate habits.** Players scan between matches; scanability, native behaviour, and two-tap reach beat decorative chrome. Express brand in condensed uppercase display headings, tabular monospaced figures, and one strict action accent.
- **Mobbin 4-archetype trawl (`design-craft:design-craft`, `ux-craft:ux-craft`):** query `mobbin__search_screens` / `search_sections` (limit 4 to 8, pass `exclude_screen_ids` on follow-ups) for 4 distinct archetypes: (1) dark spec/readout sheet, (2) split-view reading guide, (3) ranked tier list, (4) grouped settings. Decode inline base64 images from `content[]` (bare `curl` on `image_url` returns `302` 0-byte files), assemble `magick montage` sheets (or `sips` if `PIL` is absent), record a **Take / Leave** table in `ios/DESIGN.md` citing each `mobbin_url` (e.g., took Halide's label-left/mono-value-right readout, MacroFactor's tabular figures + thin target bars, Phantom's ranked rows; left per-row icons, ring charts, rank medals, purple ground, and Apple Games store tiles).
- **Token architecture (derive from the target game's world; never copy MW4's palette blindly):**
  - 4-step shadowless tonal ramp (`bg`, `bg2`, `panel`, `panel2`) + 2 hairline tiers (`line`, `line2`), where depth comes from surface steps with zero drop shadows.
  - 3 text tiers (`text`, `muted`, `dim`) checked at `>=4.5:1` inclusive via computed Python WCAG check.
  - 1 hot action/selection accent (`hot` + `hotInk`, capped at **<=2 elements per screen**), 1 dedicated measured-figure accent (`lab`, used ONLY on measured numbers), plus status tones (`ok`, `mid`) always paired with a geometric shape (10 pt filled/half-filled square) and a word.
  - 4 pt spacing scale (`4, 8, 12, 16, 24, 32, 48`), 4 pt chip corners, 8 pt card corners, 680 pt max readout width.
  - 3 bundled OFL fonts fetched from `https://raw.githubusercontent.com/google/fonts/main/ofl/...` (note variable filenames like `IBMPlexSans[wdth,wght].ttf`) and checked via `fc-scan --format "%{family} | %{postscriptname}\n"`, all scaled with Dynamic Type (`relativeTo:`). Lift `:root` tokens verbatim from `guide/site.css` into `ios/DESIGN.md`.
- **Banned on every screen:** purple or neon gradients, cream/off-white editorial defaults, glass cards over content panels (native Liquid Glass stays on tab bar, toolbars, and mini player only), emoji, rainbow tier-letter badges, drop shadows on flat cards, publisher marks/impersonation, self-awarded `"verified"` badges, and >2 hot-accent elements per screen.

## 2. Tactile iOS shaders, motion, cutouts and haptics

Every shader passes colours in from `Theme.swift` so palette stays single-source, and every animation drops to its still form under Reduce Motion.

- **Four stitchable SwiftUI Metal shaders (`Shaders/Effects.metal`):**
  1. `uplink` (launch overlay, mirrored in WebGL `guide/home.js`): 5-octave fBm topographic contours lit by a rotating radar sweep, range grid and rings, circular radar blips (masked dots, never unmasked square cells), scanlines, grain, and an expanding hot-rimmed iris revealing Brief. Start sequential steps after a 150 ms first-frame settle (not wall-clock timestamps from `bootStart`, which a ~2 s debug launch stall consumes unseen) and sync hero meta-card 3D entrance via `AppState.revealed`.
  2. `commsOrb` (live voice scope): 4 concentric graticule rings, 10°/30° outer ticks, faint crosshair, rotating radar sweep during connecting/thinking states, periodic seam-free audio-reactive waveform ring (`ringNoise`) + echo ring + subtle disc grain; ink while listening, hot accent while speaking.
  3. `benchGrid` (weapon/map bench): dual 14 pt / 56 pt grid, radial vignette, and tilt-tracking soft overhead light.
  4. `scanReveal` (layerEffect title sweep): left-to-right reveal behind a chromatic-split hot scanning edge, once on appear, zero scanline residue afterwards.
- **Tactile controls and cutouts (`Common/Effects.swift`, `FieldExtras.swift`, `scripts/lift-guns.sh`):**
  - `MotionTilt`: ref-counted (`begin()`/`end()`) 60 Hz `CoreMotion` attitude measured relative to how the player holds the phone on appear, smoothed `0.85/0.15`, disabled under Reduce Motion.
  - `InspectPlate`: on-device Vision foreground cutout (`VNGenerateForegroundInstanceMaskRequest`, 4% padding, `pngquant` 80–95 -> ~1.1 MB PNGs; WebP for web) floating over `benchGrid` with tilt-offset drop shadow, one-shot `plusLighter` masked specular metal glint on load, 3D tilt (`16°` yaw / `10°` pitch, perspective `0.6`), UIKit `HorizontalPan` (`abs(v.x) > abs(v.y) * 1.2`, never fighting `ScrollView`), and spring-back.
  - **3D Map Table:** official overhead map laid back `50°` (`perspective: 0.55`) over `benchGrid`, rotated by drag, pinched to zoom, double-tapped flat.
  - **Micro-craft:** `.contentTransition(.numericText())` rolling numbers wherever values change in place; `.scrollTransition(.animated(.spring(...)).threshold(.visible(0.15)))` `revealOnScroll()` on cards; scrubbable Swift Charts ticking selection haptics; inset `Capsule` selection indicator inside inset-grouped list rows; purposeful haptic map (selection on pickers/chips/tabs; light impact on plate grab & map flat/table toggle; success on voice open; error on voice fail).

## 3. Web opening shader, progressive enhancement, media and app icon

- **Opening WebGL boot (`create-website:create-website` `references/hero-media.md`):** author-time assets only, WebGL check with still fallback, device pixel ratio capped at 2, pause offscreen/hidden, handle `webglcontextlost` and dispose GPU objects, `aria-hidden="true"` decorative canvas with copy/CTAs in HTML, once-per-session boot skipped under reduced motion or URL anchors and dismissed by click/key/scroll. Reduce multi-item 3D hero cutout stacks to 1 full-strength render at 390 px.
- **Progressive enhancement & DOM/CSS hygiene:** core content renders with `javaScriptEnabled: false`; 5 JS-free `<details>` desktop nav groups (`.ngrp`/`.navmenu`, checking `<nav>` for legacy `mask-image` clipping) + plain-list `<details class="mnav">` phone sheet; `<article>` stretched-link cards (`::after` `inset: 0; z-index: 1`) with raised citations (`sup.c a` `z-index: 2`); JS-applied `.rv` classes paired with a `requestAnimationFrame` scroll sweep; `100dvh` dialogs; `align-self: start` on side-by-side output grids; `textContent`/`setAttribute` (never `innerHTML`); `try/catch` around `localStorage`; `[hidden] { display: none; }` on styled toggle buttons; check `c.width !== px || c.height !== px` on canvas orbs; split `background: color url(...)` into longhands for contrast linters; use `var(--dim)` + strikethrough/dashed border on disabled buttons; never start HTML `id` with a digit (`#uw-5k2k`, not `#5k2k`).
- **Explainer media (`media-gen-pro`):** GPT Image 2.6 Flare uses `size` (not `aspectRatio`). If `generate_video` times out at `-32001`, check `outputDir` before retrying a billed call; transcode MP4 via `ffmpeg -an -c:v libx264 -crf 26 -preset slow -movflags +faststart -vf "scale=1600:-2"`. When rasterizing a 1200x630 `og.svg` with `qlmanage -t -s 1200`, crop the 1200x1200 square with `sips -c 630 1200`.
- **App icon (`create-mac-icon:create-mac-icon`):** pick 2 distinct directions (`Dark-Field Emissive`, `Instrument Emblem`), generate 6 takes (4 + 2) via `media-gen-pro` `generate_image` (`style: "flare"`, GPT Image 2.6 Flare) referencing live site/app captures + 2 dark corpus icons. Review squircle-masked sheets at 280/64/40/32/29/16 px + greyscale against the 12-point rubric (`>=10/12`, 0 failures on checks 1–4), drop takes repeating rejected motifs, ship opaque 1024 px PNG for iOS + `apple-touch-icon.png` (180 px) + `favicon-32.png` (32 px), and log the raster-master deviation in `design/icon/README.md`.

## 4. Two-tier live voice guide (GPT-Live 1.1 + Haiku 5.5)

- **Flow:** `POST /api/live/token` checks caller/limits -> mints GPT-Live client secret (`POST https://ai-gateway.vercel.sh/v1/realtime/client-secrets`, `{"model":"openai/gpt-live-1.1","routeKind":"live"}`) + 10-min HMAC agent token -> returns live/agent URLs/tokens, `liveBriefing()` instructions, opening line, server-chosen `voice`, duration cap (300 s). Clients open WebSocket `wss://ai-gateway.vercel.sh/v1/live/sessions` (subprotocols `ai-gateway-realtime.v1`, `ai-gateway-auth.<token>`), send `session.start` (24 kHz mono PCM16, 960 B / 20 ms chunks, `store: false`, `audio.output.voice`), wait for `session.started`, send opening via `session.commentary.append` (GPT-Live never speaks first) and screen context via `session.thinking.append` (`<=500` tokens), and send graceful `session.close` -> `session.closed`.
- **Gateway, SDK v7 & Haiku rules:** `/v1/realtime/client-secrets` refuses `VERCEL_OIDC_TOKEN` (HTTP 403) and requires a monthly-capped `AI_GATEWAY_API_KEY` (`vercel ai-gateway api-keys create --limit 10 --refresh-period monthly --alert-thresholds 75,100`) behind `@vercel/functions` `getCache()` soft limits (non-atomic under bursts), nonce-keyed per-token caps (40/token), 16 KB body limit, timing-safe app-key check, team-pinned preview origin regex (never `*.vercel.app`), refund-on-error limiters, and data-not-instructions prompt-injection framing. Gateway supports WebSocket + client delegation only. In `ai@7.0.179`, pass system prompt in `instructions` (not `messages`). On `anthropic/claude-haiku-5.5`, set `maxOutputTokens: 400`, `thinking: { type: 'disabled' }`, prompt caching on full guide, first-person prompt (`<=70` words), no thinking aloud, regex strip for `"<Name> says:"`, and 1-sentence off-topic/cheat refusal.
- **Briefing-first latency, retrieval & probing:** keep `liveBriefing()` `<50,000` chars (~10.7k tokens, under GPT-Live's 16,384-token cap), gated by a `braindump:braindump`-style retention test asserting 100% presence of picks, GPUs, maps, settings, and perks. Wait up to 2 s (`400 ms` quiet) after `session.delegation.created` for `input_transcript.delta` to settle, instruct GPT-Live to name the entity aloud as fallback, normalize speech-recognition numbers (`"ten eighty"` -> `1080p`, `"fifty ninety"` -> `5090`), and inject matched hardware lines with explicit `reachable`/`NOT reachable` phrasing. Probe via `web/scripts/voice-probe.ts` (`elevenlabs/eleven-flash-v2.5` -> 24 kHz PCM -> live WS) timing **`afterResult`** (wait after `session.commentary.append`), never `firstAudio` (filler `"Checking..."`).
- **Live voice sampling & Swift 6 client safety:** read OpenAI primary markdown docs (`Accept: text/markdown` on `developers.openai.com/api/docs/guides/live-conversations`) for `audio.output.voice`; detect end-of-speech in `live-voice-samples.mts` via voiced PCM `RMS > 0.01` (continuous silence deltas time out at 30 s), trim 0.3 s pad, verify via pitch + Scribe. On iOS, build `AVAudioNodeTapBlock` in a `nonisolated static` helper copying buffers into `@unchecked Sendable`, pass `format: nil` + lazy `AVAudioConverter`, always `removeTap` in `stopAudio()`, restart on `.AVAudioEngineConfigurationChange`, audit all `@MainActor` background callbacks across `Sources/` (including `MPMediaItemArtwork`), and arm/verify the tap via `AVAudioEngine` `enableManualRenderingMode(.offline)` on a background queue.

## 5. Audio production, mixing and 4-part blind QA

- **Pipeline (`web/scripts/gen-audio.mjs`):** hash-cached by model/voice/text/options across `elevenlabs/eleven-v4` (~$0.08/1k chars), `music-v2.5` (~$0.0025/s), `sound-effects-v2` (~$0.002/s), `scribe-v2` (~$0.00006/s). Defer full narration until after Stage 2's audit; run `--dry` and report cost first (~$0.02 intro speech, ~$1.40 full 33-clip set, ~$0.33 5-clip patch, ~$0.77 27-clip voice swap). Normalize units (`ms`, `m`, `%`, `fps`, `DLSS`, `TTK`), pass terse cells through a prose helper (`bring(fits)`), derive counts from `guide.json`, and read intro captions from `clips.json`.
- **Radio mix (`scripts/mix-intro.sh`):** `highpass=f=450,lowpass=f=2700,acompressor=threshold=-22dB:ratio=6:attack=4:release=80:makeup=4,aeval='tanh(3.2*val(0))/tanh(3.2)':c=same,equalizer=f=1600:t=q:w=1.0:g=5,acrusher=bits=9:mix=0.22:mode=log,lowpass=f=3000,volume=1.1` + `sidechaincompress=threshold=0.06:ratio=3` + `loudnorm=I=-16:TP=-1.5:LRA=11`. Use `atrim=end=$END`, never `atrim=0=$END`.
- **Four-part blind audio QA:** (1) `scribe-v2` transcript diff (`check-audio.mjs`), (2) `ffmpeg` `ebur128` loudness + `showwavespic` PNG, (3) `google/gemini-3.8-flash` sound-engineer critique (`describe-audio.mjs`, `maxOutputTokens: 3000`), (4) Python+NumPy (using a Python binary with `numpy` installed) FFT spectral flatness (prompt SFX excluding tones/beeps/whistles; reject ~0.05 whistles, accept 0.20–0.65 broadband click/squelch) + median pitch for sample spread, while always letting the owner pick narrator voices by ear via Finder samples + `AskUserQuestion`.
- **Playback:** 10 Hz observed `position` clock in SwiftUI (`AVAudioPlayer.currentTime` is unobservable); UIKit sideways-gated `Scrubber` (`hitHeight: 18` in mini player, `44` inline) + `changePlaybackPositionCommand`; `.ambient` for auto launch comms (once/day toggle) vs `.playback` + pause narration + Stop + live captions for user-tapped `"Play it now"`. Verify web drag scrubbing on HTTP `206` Range-capable hosting (not `python3 -m http.server`, which returns `200`).

## 6. Shipping, visual critique loop and failure modes

- **Vercel & DNS:** `scripts/build-web.sh` -> `vercel deploy --prod --scope <team> --yes`; check protected previews with `vercel curl`, cache-bust prod `curl` with `?x=$RANDOM`, parse `vercel logs requests --json` under `.data`. Keep `MW4APIBase` + `MW4APIFallback` in `ios/Secrets.xcconfig`. Namecheap's DNS API replaces all host records on write; read every record first or ask the owner to add the single `A` record.
- **App Store Connect & TestFlight:** read `~/.config/app-store-connect/accounts.md`; run `provision-app.sh` read-only then `--apply`; sleep ~20 s after `apps create`; bump `CURRENT_PROJECT_VERSION`, run `xcodegen`, archive manually (`Apple Distribution`), check `CFBundleDisplayName` via `PlistBuddy`, upload with `--locale en-US --test-notes ... --wait`; verify `VALID` via `--build-id`; invite via `testflight testers add`, skip `builds add-groups` on `--access-all-builds` (HTTP 422), verify groups via `groups builds list --group-id`, check `INVITED` testers, log in `accounts.md`. Survey ASO via iTunes Search API, enforce 30-char cap on `name`/`subtitle`, verify via `--read-only localizations list`, ship dismissible `"Coming soon to the App Store"` banner until release.
- **Visual critique & testing protocol:** arm regression tests against broken code first (`DiagnosticReports/*.ips` confirms crash stacks); run full `xcodebuild test` with `run_in_background: true` (exceeds 600 s foreground timeout); mute Mac audio (`osascript -e 'set volume with output muted'`) before simulator launches; grant mic via `xcrun simctl privacy`; select Xcode 27.1 via `DEVELOPER_DIR` (never `xcode-select -s`); capture Duo with `--display=1` (closed) / `--display=3` (open) + `-split` + `fold:` console logs + `magick montage`/`ffmpeg hstack` sheets + `recordVideo`; ask owner before driving Device Hub with a Swift `CoreGraphics` clicker guarded by System Events frontmost check (`*Device*`) + `flags = []`, and log 3 unreachable poses (Split View left/right, PiP). On web, run `ux-lint.py --static`, `design-lint.py guide/site.css`, Python WCAG contrast, 4-pass `scroll_capture.mjs`, 1440/390 px + `javaScriptEnabled: false` captures, inner `.tblwrap` width probes, `.top{position:static!important}` before element captures, `--session <name>` on every `agent-browser` call, HTTP 200 checks on local ports, 800 ms post-transition settle, fresh session for cached scripts, IIFE `(async () => { ... })()` in `eval --stdin`, and real `click`/`mouse` events. Avoid stock-macOS-absent `timeout`, unquoted `grep --include=*.ext` / `echo ====`, unsplit zsh strings, macOS `ugrep` on single-line captions, trailing `-R` on `ls`, `${PIPESTATUS[0]}`, and `.ts` top-level `await` (use `.mts`).

### Consolidated failure modes

| Symptom | Cause | Fix |
|---|---|---|
| App crashes at launch after data edit | Untested numeric `""`, or renamed/non-optional key | Export `null`; additive `Optional` schema; 2–4 s `swiftc` decode harness |
| `import site` fails in exporter/audit | `build/site.py` shadows Python stdlib `site` | Load via `importlib.util.spec_from_file_location('gsite', ...)` |
| Citation digits glued (`Beta234`) | Generic HTML strip left `<sup>` text | Strip `<sup ...>...</sup>` before removing remaining HTML tags |
| App crashes on phone when voice opens | `@MainActor` tap traps on audio thread | `nonisolated static` tap copying buffers; audit `MPMediaItemArtwork`; offline `AVAudioEngine` test |
| Open-flat Duo list pane squeezed | `TabView` leaks trailing sidebar inset | Widen list `+ geo.safeAreaInsets.trailing`, pad `-trailing`, `zIndex(0)` under detail `zIndex(1)` |
| Device Hub clicks miss or do nothing | Window focus lost; inherited `CGEvent` flags | Ask owner; System Events `*Device*` frontmost check + `flags = []` |
| Token route HTTP 403 / `AI_InvalidPromptError` | OIDC on client-secrets; `role:'system'` in `messages` | Monthly-capped `AI_GATEWAY_API_KEY`; pass system prompt in `instructions` |
| Delegated voice empty or `"Overwatch says:"` | Haiku thinking exhausted 220 tokens; 3rd-person prompt | `maxOutputTokens: 400`, `thinking: { type: 'disabled' }`, 1st-person prompt + regex strip |
| Voice slow, misses GPUs, or probe reads 99 ms | All-fact delegation; transcript race; spoken numbers; filler timing | `<50k`-char `liveBriefing()`; 2 s + 400 ms quiet; normalize numbers + inject card lines; time `afterResult` |
| Voice sampler hangs 30 s | Continuous silence PCM deltas | Detect speech end via voiced `RMS > 0.01`, trim 0.3 s pad |
| Progress frozen or scrub fights scroll | `currentTime` unobservable; SwiftUI `DragGesture` | 10 Hz observed `position`; UIKit `HorizontalPan` (`abs(v.x) > abs(v.y) * 1.2`) |
| `"Play it now"` silent / web seek snaps to `0:01` | `.ambient` obeys mute switch; `http.server` returns `200` | `.playback` for user tap; test web seek on Vercel `HTTP 206` with `agent-browser mouse` |
| Radio SFX whistles / mini player clips title | Tonal chirp (flatness 0.05); 44 pt scrubber in 48 pt bar | Prompt PTT click/static (flatness 0.20–0.65); `Scrubber.hitHeight = 18` |
| Search missing / selection bar clipped / dark gun boxes | `.toolbar` placement; outer edge under corner; uncut JPGs | `.navigationBarDrawer(displayMode: .always)`; inset `Capsule`; Vision cutouts (`lift-guns.sh`) |
| Web dropdown hidden / orb `300x150` / hidden button shown | `.top nav` `mask-image`; width-only check; missing `[hidden]` | Bisect `elementsFromPoint()`; check `width \|\| height`; `[hidden] { display: none; }` |
| Cards stay invisible / grid breaks / `#5k2k` throws | Fast jump skips `IntersectionObserver`; nested `<a>`; digit id | JS `.rv` + rAF sweep + `scroll_capture.mjs`; `<article>` + `check-html.py`; `#uw-5k2k` + `.tblwrap` probe |
| Launch animation unseen / blips square | Wall-clock steps eaten by ~2 s stall; unmasked hash cells | Sequential sleeps after 150 ms settle; circular dot mask; check `recordVideo` |
| Contradictory chips / `"Big cost"` on DLSS / 18 empty chips | Separate flags; unsigned `"Big"`; empty `flagLabel` | Unified `AgreementChip`; `"Big gain"` for `+`; suppress empty `flagLabel` |
| Dossier wrong brief, `sources: 0`, false negatives | Auto `competitive` archetype; 10 m cutoff; bot walls; codex log dump | Override archetype; pair 2+ families + direct `curl`; keep `stalled` alive; read raw tail/`measurements.json` |
| Silent YT, Mobbin `302`, Steam/Reddit blocked | No captions; `image_url` redirect; `appreviews` `302` / Reddit `403` | Chapter 2–3 s `yt-dlp` + `magick` zoom; base64 `content[]`; `steamcommunity.com` + `homecontent/` & 25 s `.rss` |
| Deploy/ASC checks empty or 422 / name >30 / Swift 6 error | Edge cache; `apps create` lag; `hasAccessToAllBuilds`; isolation bug | `?x=$RANDOM`/`vercel curl`; 20 s sleep; `testers add` + `--group-id`/`--build-id`/`--locale`; 30-char subtitle; `@MainActor` + timeout `Task` |
| Bash secret masking leaks key | `${KEY:+present}${KEY:-MISSING}` echoes `$KEY` | Compare keys by SHA-256 digest; omit secret values from stdout |
