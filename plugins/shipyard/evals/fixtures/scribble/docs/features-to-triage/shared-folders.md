# Shared folders

- origin: founder voice note · 2026-08-14
- audience: small teams keeping notes together

## What and why
People want to put notes into folders and share a whole folder with teammates.
Sharing should work like the existing single-note sharing. Folders need a way
to be renamed and archived too. It should feel fast.

## Acceptance sketch
- A user can create a folder and drag notes into it
- Sharing a folder gives a teammate access to all its notes
- Renaming and archiving a folder works from the folder menu
