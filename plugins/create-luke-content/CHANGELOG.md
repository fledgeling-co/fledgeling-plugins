# Changelog

## 3.2.0 - 2026-09-08

The voice gains a prohibition it was missing, and it is about how a fault gets described. Luke names the actor and the number; the register this release bans names neither.

- **No noir case-file register.** "I recorded a merge that had not happened", not "a merge that had never happened"; "the verify command re-hashed 30 digests it was checking", not "the command meant to check the evidence overwrote it". Three shapes make that register and they compound: an event named by its absence, a passive or abstract subject where an actor belongs, and an ironic reversal closing the clause. A verbless noun phrase does the same thing in one line, so a finding goes in a sentence carrying what happened and what it cost.
- **`references/ai-writing-signs.md` gains §1.8** with the three shapes, the measurement behind them (a status page carrying fifteen consecutive actorless fault lines, which its reader read as a noir case file) and the rewrites.
- **Five literal fragments added to `scripts/voice-lint.json`'s `advisory_phrases`**, warning rather than failing, with the note recording why: the shape needs judgement, so the lint catches its commonest phrasings and the writer decides. Verified firing on both measured examples.
