# Current Moves — dated axes, not a costume checklist

Read this when choosing a direction and you need axes that are not the 2024–26 AI defaults (cream editorial, dark plus one acid accent, the soft-glass showcase, the three-card bento). It is a candidate list for `frontend-aesthetic-direction.md` and `aesthetic-worlds.md`, not a look to apply wholesale.

**As-at 2026-11-22.** Last reviewed 2026-11-22. A page that wears every row is a trend collage, which is the other way sites look the same. Treat each row as a permission the current year has granted, then still subject-mine. Take at most two rows into one direction, and name them in the direction contract so the lookalike gate can check them.

## How to read a row

| Field | Meaning |
|---|---|
| **Strength** | `measured` a documented standard, API or shipped browser support; `repeated-shipped` a named public pattern shipped by more than one team; `forecast` a vendor trend report built on its own search or template data; `practitioner` a skill, studio or designer observation |
| **Source** | The URL or repo snapshot that supports the row |
| **Accessed** | The date that source was read for this file |
| **Status** | `emerging` still distinctive; `mainstream` available and useful; `decaying` common enough that it no longer surprises on its own; `ai-default` now a reflex, do not spend a free axis on it |

**Forecasts predict briefs, not quality.** Canva, Kittl and Envato publish 2027 reports built on their own users' searches, so a `forecast` row tells you what clients will ask for next year. It never justifies a choice on its own; the subject still has to earn it. One forecaster's rule of thumb is worth carrying: if three competitors already use a cue, assume it has decayed ([WE AND THE COLOR, 2027 trends](https://weandthecolor.com/the-top-10-graphic-design-trends-for-2027-are-about-process-not-ai/212398)).

## What not to treat as current

- **The soft-glass showcase.** Frosted or liquid glass over a grainy gradient, a bento of faux-UI tiles, one large radius on everything, a highlighted hero word, an arrow inside the button, a glow on hover. Designers in Oct–Nov 2026 describe it as the look everywhere and as the kit design educators now hand agents ([@x6sense](https://x.com/x6sense/status/2122052638862705150), [@MengTo](https://x.com/MengTo/status/2122984275566076395), [@ui_jaymez](https://x.com/ui_jaymez/status/2123172666869797065), [@benjitaylor](https://x.com/benjitaylor/status/2116593247854453244)). `ai-slop-check.md` §9 counts its parts.
- **Bento as the default showcase.** It moved here from the moves table: the bento-plus-faux-UI grid is the shared showcase layout. The cell-count rule in `ai-slop-check.md` §11 still governs a bento that the content genuinely calls for.
- **The post-Inter grotesque as the distinctive choice.** Inter, Geist and Space Grotesk were the 2024–26 default stack; one interface designer calls Geist, Manrope, Instrument Sans, DM Sans, Hanken Grotesk and IBM Plex Sans the same typeface, and replies dispute it ([@hobdaydesign](https://x.com/hobdaydesign/status/2101367573820355058)). Distinctive is a pairing or a display face with a subject reason.
- **Instrument Serif, and whatever replaces it next.** Several designers name it the AI-slop serif in Sept–Nov 2026 ([@pizzaboy](https://x.com/pizzaboy/status/2106835521460994155), [@linazfowler](https://x.com/linazfowler/status/2120316932188737632)); one reply predicts Geist Serif (released 30 Oct 2026) will be swapped in for it. Treat a free screen serif arriving without a reason as the same reflex.
- **Liquid Glass on the web.** Apple retuned it in iOS 27 (darker edge, brighter highlight, a more opaque default and a user slider from ultra-clear to fully tinted) ([MacRumors](https://www.macrumors.com/2026/06/10/how-liquid-glass-is-changing-in-ios-27/)). Open-source web ports exist and run poorly on Safari and mobile ([@naaiyy_](https://x.com/naaiyy_/status/2107985803301281882)). A `backdrop-filter` approximation is honest only when labelled, and it is not a web identity.
- **"AI purple" and indigo Tailwind accents.** Still the first tell builders name in Nov 2026 ([@bozhou_ai](https://x.com/bozhou_ai/status/2123807528777863217)). A brief that asks for violet is an override, not a trend.
- **Grain overlays and halftone as a filter.** Texture applied over everything sits in what one forecaster calls the decay zone; texture that records a real event is the row above.
- **Gooey morphs and heavy bounce.** Opinion is split, but the posts that cleared an engagement floor lean toward quieter, faster, interruptible motion ([@aleksliving](https://x.com/aleksliving/status/2096640322499448922)).
- **Infinite micro-loops.** Pulse, float, shimmer on every card. Motion still has to say something (`motion-design.md` Phase 1).
- **`window` scroll listeners.** Scroll-driven CSS is Baseline as of 27 Oct 2026; use it, ScrollTrigger, IntersectionObserver, or Motion `useScroll`.

## How this file goes stale

A move that has become the new default belongs on the AI-default list in `ai-slop-check.md` §9, not here. When updating:

1. Change **As-at** and **Last reviewed**.
2. Add or replace the source URL and accessed date on the changed row.
3. Set **Status** honestly. If a row is now `ai-default`, move it to "What not to treat as current" rather than leaving it as a permission.
4. Do not add a row whose only support is "it feels current". A `forecast` row needs the vendor's own report, not a roundup that quotes it.
5. Record the sweep in `evidence.md`, with what each source class could and could not show.
