# Make a Deck — moved

Deck production lives in the **`deck-craft`** skill (same marketplace). It owns three targets from one body of deck craft: self-contained fixed-stage HTML, `lecturn.deck/1` JSON (and `.pptx` through it), and Diolog investor decks assembled from the 140-template slide library.

Invoke `deck-craft` for any slide work. It is self-contained — it carries its own direction, typography, colour, hierarchy, anti-slop and verification layers, so it needs nothing from this skill.

Kept here as a pointer so older references to `references/make-a-deck.md` still resolve.
