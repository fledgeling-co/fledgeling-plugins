# Command surface - Raycast / launcher energy

- **Family:** tools and builders
- **Best for:** launchers, productivity utilities, command palettes, extension ecosystems
- **Touchstones:** Raycast app and extension store surfaces
- **Source:** [garden-skills recipe](https://github.com/ConardLi/garden-skills/blob/aaf9a82f5efd73e87cc0998edc398e75bfc35901/skills/web-design-engineer/references/style-recipes/raycast.md) (snapshot `aaf9a82f`)

## Tokens

- **Palette:** charcoal ground, translucent surface, hairline border, one brand signal, small item colours.
- **Type:** compact sans with mono shortcut metadata.
- **Scale:** 14 to 15px body; shortcut chips are utility text, not display decoration.
- **Spacing:** 4 / 8 / 12 / 16 / 24 / 40 / 64px.
- **Shape:** 8 / 12 / 16px for controls, up to 24px for one command palette. Shadow belongs to the palette only.
- **Motion:** quick state changes; mild spring for the command surface opening or a meaningful hover lift.

## Signature moves

1. The command palette is the hero, not a fake product dashboard.
2. Shortcut chips reveal the keyboard path beside the action.
3. Extension colour is a small identity mark tied to the extension it identifies.
4. One soft-focus colour field supports the palette; it does not fill every section.

## Avoid

Do not make every tile colourful, use bright solid buttons as decoration, or show keyboard shortcuts the product does not support. Do not copy Raycast's marks or extension art.

## Do not use when

The audience does not know keyboard shortcuts, the product is not a launcher, or an enterprise tone needs neutral system grammar.

## Subject-mining prompt

What is the fastest command this product gives the visitor? Build the first viewport around that command's input, result, and shortcut.
