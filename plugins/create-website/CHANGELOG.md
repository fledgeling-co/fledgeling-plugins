# Changelog

## 0.1.0 - 2026-11-22

First release, built through `create-skill:create-skill`.

- A nine-step procedure: plan, one `trawl:trawl` run, one Mobbin reference per section, a plain
  site built through `design-craft:design-craft` and `ux-craft:ux-craft`, a motion block for every
  section, hero media (image, generated video, or 3D from a decided source), cheap effect
  iteration, verification, and shipping on the person's say-so.
- Seven scripts: `plan_check.py` (the plan), `site_audit.py` (the built files), `scroll_capture.mjs`
  (four browser passes on agent-browser or Playwright), `router_call.py` (reaches a healthy MCP
  router from one process when the session's own link has dropped), `clip_tools.py` (joins, loop seam, flash
  proxy, reverse, crossfade, grade, encodes), `deploy_check.py` (every path, range requests,
  access as a stranger, domain states) and `spend.py` (the running cost of billed generation).
  `self_test.sh` proves each check fails on a planted fault: 30 cases.
- Research: a Dossier panel of three free members (Gemini, Codex, Grok), exported to
  `docs/deep-research/` with citation checks. The approved paid seat could not run.
- Evaluated against no skill on three tasks: 28 of 28 graded checks with it, 11 of 28 without,
  and a five-family blind panel in both orders. Three defects the judges found in the skill's
  versions became rules; see `EVALS.md`.
