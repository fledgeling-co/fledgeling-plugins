# create-website — agreed brief (22 Nov 2026)

Trigger: building a complete website — personal, portfolio, small business, event, product
marketing, any multi-section content site — "build me a website", "make a site for X",
"personal site", "portfolio site", "site with a hero video / 3D / scroll animation".
Not: a launch site built from a repo's product docs (route to launch-craft:launch-craft), a single
app screen or dashboard (design-craft:design-craft), a standalone video (motion-craft:motion-craft),
a review of an existing site (design-review:design-review).

Output: a served, multi-section site built from one direction; per-section reference ledger;
media (hero image, optional hero video, optional 3D) with prompts and costs; motion throughout with
reduced-motion/no-WebGL/touch paths; scrolled verification captures at desktop and phone; a
deploy and domain checklist executed only on the person's say-so.

Required by the user: invoke trawl:trawl for ideas/inspiration; Mobbin inspiration per section;
animations throughout; hero image and 3D generation; video hero procedure; the career-kit
website learnings generalised (not résumé-specific).

Routing (call, do not reimplement): trawl:trawl, design-craft:design-craft (+ its
generate-images, gsap-motion, depth-and-3d, mobbin-trawl, aesthetic-ideation, motion-design,
visual-verification references), ux-craft:ux-craft, motion-craft:motion-craft (for video pieces
made from code), design-review:design-review, decision-panel:decision-panel (concept contact
sheets), media-gen-pro MCP (image, video), Mobbin MCP, a registrar MCP (read checks), Warden for
credentials.

Hard constraints: deploy, purchase a domain, or publish only on explicit say-so; state price
before the first billed generation and the running total after each; never route around a model's
refusal on its own; review tools (choosers, comparison controls) never ship; an unlisted URL is
public; check every path on a domain before its address is shared.

Checkability: mixed. Structural (scripts): every referenced asset resolves, no review-tool block
in the deploy build, reduced-motion and no-WebGL fallbacks present, horizontal overflow, console
errors, poster/resting frame present, video size budget, every path on a host listed. Judgement:
the design — blind panel.

Research: design-craft and design-review corpora reused; a narrow paid Dossier panel (user chose,
~$1–3 fast tier) on the gap: generated video on the web, scroll-motion and WebGL performance and
accessibility, 3D asset delivery, static-site deploy visibility.

Stated assumptions: 3D means real-time three.js scenes, scroll-linked depth and generated
3D-styled imagery, because no 3D-mesh generator is connected (AI Gateway lists none, 22 Nov 2026);
if one appears at runtime the skill uses it. Name: create-website (user's). New plugin.
