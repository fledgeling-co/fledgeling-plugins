# Kettle

A small invoicing tool for freelancers. Next.js front end, a Postgres
database, deployed to Fly.io on push to `main`.

- `src/` — the app
- `config/` — per-environment settings
- `docs/` — roadmap, deploy log, decisions
- `notes/` — call notes, not tidied up

Run it with `pnpm dev`. Tests are `pnpm test` (191 passing).
