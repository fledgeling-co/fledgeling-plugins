# Ledgerline — macOS app icon, delivery note

Menu-bar app that tracks personal cashflow. Brief personality: **calm,
precise, trustworthy**. No existing brand, no colour constraint, no reference
image supplied — every call below is mine and recorded.

## Ship this

**`ledgerline-a.svg`** — the layered master, 1024×1024, full-bleed, no baked
corners or shadow. Four named layer groups (`bg` / `mid` / `fg` / `highlight`)
that map 1:1 onto Icon Composer. Generated by **`build_icon.py`**; edit the
constants at the top of that file and re-run, never the paths.
`ledgerline-a-preview.svg` is the same artwork clipped to the system squircle,
for previewing only.

## The spec

**Direction — Tahoe Gel-Glass, sub-register (b):** saturated single-hue gel
tile carrying a white *frosted* glyph. This is the Mail / App Store / Weather
recipe and the corpus calls it the single most reusable system construction.
Runner-up was **8 Instrument Emblem on porcelain**, rejected because a
near-white ground gives a menu-bar utility no colour identity in a Dock full
of saturated tiles, and this mark's carrying mass wants a field behind it.

**Device — "the stepped ledgerline".** A running balance moves in discrete
transactions; it does not curve. So the mark is a **step function**, not the
smooth line every finance icon reaches for. Its top edge *is* the ledger's
rule, and it bleeds off both tile edges so the squircle reads as a page rather
than a frame (device #18, edge-bleed physicality). The profile falls once
before it recovers — the dip is the ownable claim, and a monotonic staircase
would be the generic growth chart (anti-checklist #1, template genericism).
Three ultra-low-contrast rules cross the teal above it as ledger paper (Tahoe
tell #9, quiet patterned grounds). One amber gel dot marks "now" on the final
tread with a halo bleeding onto the ground, the Reminders construction.

**Palette — one hue family plus one bounded accent.** Deep sea-teal ramp
`#2C9689 → #12727A → #053C49`, amber `#FFD37A → #EE9E17` reserved entirely for
the "now" datum. Blue and indigo were declined: the reference catalogue flags
them as the corpus's template default needing positive justification, and
they are also the finance category's reflex. Money-green was declined for the
same reason. Ledger-ink teal is under-used, reads institutional and calm, and
still gives the Dock a colour to recognise.

**Light — one soft top source.** Lit lip along the stepped edge, an inner
bevel below it so the frosted panel is set *into* the tile, a cushion vignette
and top sheen, and exactly one catchlight on the dot. No hard speculars.

**Layer plan (#10):** `bg` tile ramp + rules + sheen + vignette · `mid` lip
bloom + frost mass · `fg` inner bevel + dot contact shadow + dot · `highlight`
lit lip + dot catchlight. Identity rides on shape and value; the amber is the
only second hue and it is droppable under tinting.

## The fidelity loop

C2 won the material judgment, so the master was rebuilt against it —
baseline plus four bounded rounds, full log and every round's residuals in
**`runs/`** (`runs/LOG.md` is the readable version). Total composite
**1.273 → 3.163**.

The finding worth carrying forward: **the gate accepted the state that failed
the rubric and rejected the state that passed it.** The raster's frosted panel
has a measured figure-ground contrast of 1.41:1 — luxurious at 1024, mush at
16px. Converging on it (r02) scored highest at 1024 and dropped the master to
1.02:1, hard-failing checks #7 and #4. Restoring the value gap (r03) was a
gate REJECT and a rubric PASS. Round 4 then recovered the similarity **only in
the base region**, below the point where any figure-ground boundary lives, and
produced both the run's highest total and its best 32 / 16px scores. The
shipped master reads **3.08:1** and **3.01:1** at its two tread boundaries
against the reference's 1.41:1.

Two constructions were confirmed and are written up in
**`material-recipe-addition.md`**, ready to paste into the skill's
`references/material-recipes.md`: the bounded frost fade, and drawing the lip
bloom *under* the mass so it is occluded on its inner half.

## Known liabilities

1. The base fade bottoms out at 1.27:1 against the tile — the bottom quarter
   of the mass reads soft and the tile is doing more work there than the
   frost. This is the #8 deduction.
2. The mark bleeds off three edges by design; a future system mask more
   aggressive than the current squircle eats more of the left tread than
   intended.
3. The amber dot sits 91px from the right edge at y=300 and can read as a
   notification badge in peripheral vision at Dock size. Worth testing against
   a variant with the dot inboard on the tread.
4. At 16px the read is carried almost entirely by the stepped boundary; the
   lower mass merges toward the tile. It survives, but there is no second cue
   if an OS applies a heavier tint.
5. No dark-mode-specific variant has been authored. The layer split makes one
   cheap, but it has not been drawn or measured.
