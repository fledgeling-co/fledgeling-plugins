# Changelog

## 1.2.0 - 2026-11-13

Reads a session in full instead of sampling it. `scripts/render_transcript.py` turns one session into a Markdown transcript with stable `#N` event anchors, then plans the read against a token budget the caller passes: the whole transcript when it fits, otherwise chunks of about 120,000 tokens (at most 8), each with a filled reader brief in `briefs/`. User and assistant messages are never shortened; tool calls collapse to one line naming their command or path, and tool output is clipped at the richest of four detail levels that fits. The reader brief (`references/chunk-reader-brief.md`) carries braindump's Tier-1 method: per-category sweeps for constraints, corrections, method and product dead ends, and identifiers, every item anchored, so the parent merges rather than trusts a summary. The briefing now opens with a pinned block and a REREAD list ahead of the six dimensions.

Privacy. Rendered transcripts default to `~/.cache/resume-session/<session-id>/`, created owner-only (mode 0700); the renderer refuses a symlinked or foreign-owned output path, where the old `/tmp/resume-session/` default was a predictable path another local user could pre-create. Carried-in user messages, transcript headers and manifest titles now pass through the same redaction as the transcript body. SQLite indexes (Muse, AGY, Cursor) open through one read-only helper that falls back to an immutable read when a WAL database is busy, and the Muse renamed-session lookup now queries the right column.

New sources and references. Muse Code sessions (`~/.local/share/muse/sessions/`), including lookup by session name through `session-index.db`, model and branch changes, the run's terminal reason, and the session's last todo list. `--ref` accepts `codex://threads/<uuid>` deeplinks, chatgpt.com/codex URLs, any URL carrying a UUID, and Muse session names.

Safety. A UUID prefix that matches more than one session now makes both scripts exit 2 and list the candidates instead of silently taking the newest; Codex, Muse and Grok all issue time-ordered UUIDv7 ids, so on this machine every November 2026 session in all three starts `01a1`. When the user names the tool, the skill passes it as `--cli`. Claude Code messages typed while the agent was mid-turn (stored as `queue-operation` enqueue rows) now appear in the transcript as user turns, de-duplicated against ordinary user rows, and skill bodies and task notifications no longer count as user messages. Re-rendering a session moves earlier reader findings to `findings.prev-<time>/` rather than deleting them. Each render now has a `render_id` and its own `findings/<render_id>/` directory, after an eval run built a briefing from 6 of 8 chunks by reusing findings an interrupted run had left behind. When the harness cannot spawn subagents, the skill reads the chunks itself in order, writing each chunk's findings before opening the next. Each constraint a reader reports names its source (user message, instruction file, or refusal), after a test reader listed the agent's own receipt fields as project rules.

Fixes. Codex: titles come from `session_index.jsonl`, the injected AGENTS.md and environment_context messages no longer count as the first prompt, files written through `apply_patch` are recorded, and archived rollouts (including `.jsonl.zst`) are searched. AGY: the parser recognises the current `read_file`, `write_file` and `edit_file` tools and their `Path` argument (it previously recorded almost no files), reads titles and workspaces from `conversation_summaries.db`, and renders from `transcript_full.jsonl`. The briefing no longer reports an unknown branch as `main`, names each CLI's native resume command, and masks secret-shaped strings.
